# マッスルリンゴクラッシュ
ルールは簡単、スペースキーを連打して**りんごを潰せ！**

今日から君もりんごクラッシャー！

## 【概要】
突然ですが皆さん、
**りんごを握り潰したい**って思ったことありませんか？

ほら、一度は見たことあるでしょう。筋骨隆々なマッチョが圧倒的な握力でりんごを「フンっ！」って握りつぶすやつですよ。

そのシーンを見てあなたは思ったはずです。

「わあ...！かっこいい！！やってみたい！！憧れるゥ！！」

## でも...

そんなあなたの前にこんな問題（現実）が立ちはだかりました。

【でも、私、マッチョじゃないからできない...】

【りんご潰すと果汁で洋服が汚れちゃうからな...】

【最近、物価高でりんごも高くなってきたから...迂闊にりんご潰しなんてできないよ...】


そうやって、りんご潰しをあきらめてしまったあなたの為に、このアプリを作成しました。

当アプリは、誰もが一度は夢見たことがあるであろう「りんごを潰す」夢を叶えるためのアプリです。

さあ、ためらうことはありません。りんごを潰しましょう。

## ルール
制限時間は20秒間。
その間にスペースキーorパッドを連打し、どれだけのりんごを潰せるかを競うゲームです。
連打し続けるとコンボが加算されて、より早くりんごを潰せます。

潰した個数に応じて称号がゲット出来ちゃいます。


## 注意事項

#### ※実際のゲーム画面ではマッチョは登場しません。私の技術力不足です。涙を禁じ得ません。

#### ※スペースキーやパッドが劣化しそうなので何度もプレイすることは推奨しません。
