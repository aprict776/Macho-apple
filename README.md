# マッスルリンゴクラッシュ
ルールは簡単、スペースキーを連打して**りんごを潰せ！**

今日から君もりんごクラッシャー！

## 【概要】
突然ですが皆さん、
**りんごを握り潰したい**って思ったことありませんか？

漫画や映画で一度は見たことあるでしょう。筋骨隆々なマッチョが圧倒的な握力でりんごを「フンっ！」って握りつぶすやつです。
かっこいいですよね。でもいざ自分でやるとなると、

【私、マッチョじゃないからできない...】

【りんご潰すと果汁で洋服が汚れちゃうからな...】

【最近、物価高でりんごも高くなってきたから...迂闊にりんご潰しなんてできないよ...】


などの壁が...


りんご潰しやってみたいけど、そんな壁にぶつかって諦めてしまったあなた。
そんなあなたのためのアプリです。

このアプリにたどり着いた今ためらうことはありません。**存分にりんごを潰しましょう。**

## ルール
制限時間は20秒間。
その間にスペースキーorパッドを連打し、どれだけのりんごを潰せるかを競うゲームです。
連打し続けるとコンボが加算されて、より早くりんごを潰せます。

潰した個数に応じて称号がゲット出来ちゃいます。
最上位のガチマッチョはかなりシビアな個数に調整しています。達成できたあなたは真のガチマッチョです。


## 注意事項

#### ※実際りんごを潰す場面ではマッチョは登場しません。私の技術力不足です。涙を禁じ得ません。

#### ※スペースキーやパッドが壊れそうなので、何度もプレイすることは推奨しません。
